# Design: 拍后轻量预设微调

## Context

拍摄结果页目前在对话框中显示预览、原片对比和保存按钮。成片由 `PhotoColorProcessor` 从捕获源生成；AI 裁剪路径传入的捕获源已是裁剪后的高分辨率 JPEG。

## Goals

- 保存前可调整当前照片的预设强度并查看更新后的成片。
- 每次调节从未经风格处理的当前照片源重新处理，避免重复 JPEG 编码。
- 普通照片保留原有原片保存选项；AI 裁剪照片的任何保存选项都只包含裁剪区域。
- UI 拖动期间合并快速变化，只保留最新强度任务。

## Proposed approach

- 在结果预览中增加 0–100 强度滑杆和数值反馈。
- 使用现有单线程 `photoProcessingExecutor` 重新处理当前输入源；拖动期间以短暂 debounce 合并任务，较旧结果完成后丢弃并删除。
- 处理完成后加载低分辨率预览图替换当前图，并在保存按钮恢复可用前确认文件完整。
- 保存时按最后显示的强度输出；仅在用户保存后更新 `PhotoPresetStore` 的对应强度。重拍或关闭则不修改持久强度。
- 处理失败时保留当前可用成片，并显示错误；AI 裁剪照片不得露出或保存未裁剪全幅图。

## Risks

- 高分辨率图片反复处理会占用 CPU 和内存；通过 debounce、单线程执行和旧结果清理控制峰值。
- 用户可能在处理尚未完成时点保存；此时禁用保存按钮，明确等待状态。
- 照片可能在用户离开对话框后仍有排队任务；任务回调须检查对话框状态并清理临时文件。
