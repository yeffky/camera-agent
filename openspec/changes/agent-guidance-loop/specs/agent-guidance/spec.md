# Agent 拍摄指导闭环

## 新增需求

### 需求：按键触发、非对话式意图输入

Agent SHALL 只响应用户显式的拍摄/重新分析按键；默认使用自动判断。用户可展开不遮挡取景的单选意图项；系统 SHALL 不显示强制文字输入、聊天记录或自动弹出键盘。

#### 场景：用户不输入具体意图

- **当** 用户点击 AI 分析按钮且未选意图
- **那么** 请求按端侧场景与最新取景帧进行判断
- **并且** 不发生后台或持续图像上传

#### 场景：用户选择场景意图

- **当** 用户为当前场景选定一个意图并点击分析
- **那么** 当前请求包含该结构化意图
- **并且** 取景画面、快门和场景信息仍可直接操作

### 需求：只在当前会话保留结构化上下文

Agent SHALL 只在当前相机拍摄会话内存保留意图、上一轮结构化建议/执行结果、当前场景和相机状态；新请求 SHALL 仅包含新采集的图像。系统 SHALL 不保存或上传旧图、自由聊天文本或跨会话记忆。

#### 场景：用户移动手机后重新分析

- **当** 用户移动手机并按键重新分析
- **那么** 新请求包含最新取景帧与本会话中仍有效的意图/结构化反馈
- **并且** 不附带之前的帧或文字聊天历史

#### 场景：用户离开相机页或场景类别切换

- **当** 相机页退出或本地识别场景类别变化
- **那么** 当前 Agent 上下文被清除
- **并且** 后续请求不得引用旧场景建议

### 需求：主体与人数判断服务于美观构图

响应 SHALL 区分主体类别和单人、双人、群体、多人杂乱或不确定的人数关系，并返回有界置信度；系统 SHALL 不要求模型推断人物行为。主体/裁剪置信度不足时 SHALL 拒绝数字裁剪。

#### 场景：群体照中的裁剪建议

- **当** 模型判定画面为群体照
- **那么** 裁剪建议需保留画面中主要人物
- **并且** 无法校验主要人物均在框内时不应用裁剪

#### 场景：主体或人数低把握

- **当** 主体/人数无法确定或裁剪置信度低于客户端阈值
- **那么** 当前构图与主体保持不变
- **并且** 用户收到简短的重新取景提示，普通快门仍可用

### 需求：重取景优先于大幅数字裁剪

模型 SHALL 在需要大幅构图变化时返回用户可执行的重新取景提示；客户端仅应用保留源图像比例且保留至少 70% 取景面积的裁剪框。用户手动选定风格预设时，模型 SHALL 不覆盖该风格。

#### 场景：轻微构图修正

- **当** 主体完整且裁剪范围符合源比例/面积限制
- **那么** 系统可以在取景页预览裁剪框
- **并且** 最终输出保持当前照片比例

#### 场景：大幅重构或不合格裁剪框

- **当** 建议裁剪面积不足、会切除主要主体或无法映射到预览
- **那么** 系统拒绝裁剪并显示重新取景提示
- **并且** 只在用户重新分析后处理新画面

#### 场景：用户已选风格

- **当** 用户明确选择本地预设
- **那么** 后续 Agent 请求按该预设锁定风格
- **并且** 对颜色/预设的云端动作被跳过或拒绝

### 需求：请求标识、过期保护和可取消

每个请求 SHALL 携带版本和唯一请求 ID；客户端 SHALL 只处理匹配当前活动请求的响应。用户 SHALL 能取消网络分析；普通快门在分析期间保持可用。用户先拍照时该请求 SHALL 失效，不能稍后应用建议或触发自动拍摄。

#### 场景：旧请求晚于新请求返回

- **当** 同一会话存在新请求或活动请求已取消
- **那么** 旧响应不修改相机状态、不修改裁剪框、不触发自动快门

#### 场景：等待期间用户按快门

- **当** 云端请求仍在进行且用户按下普通快门
- **那么** 待返回请求被取消或标记失效，普通拍照继续
- **并且** 网络回调不得迟到改变该照片或后续取景状态

#### 场景：等待期间用户取消 AI

- **当** 用户点按取消分析
- **那么** 当前网络连接和临时图像被释放
- **并且** 快门及普通相机功能保持可用

#### 场景：场景/主体明显变化或建议超过时效

- **当** 响应对应的场景/主体区域已明显变化或超过 30 秒
- **那么** 响应被标记过期且不执行动作/裁剪
- **并且** 提示用户重新按键分析

### 需求：简短说明和真实执行结果分离

每条建议 SHALL 提供简短理由或构图提示；模型意图文字与客户端真实的已应用、跳过、失败结果 SHALL 分别展示。建议无效或服务失败时，普通拍摄 SHALL 不受阻。
