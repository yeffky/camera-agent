# 设计：带拍摄上下文的 Agent 指导闭环

## 请求与会话上下文

增加内存态 `AgentCaptureContext`：`session_id`、可选单项 `intent_id`、上轮建议摘要、客户端实际应用/跳过/失败结果、请求时场景名/置信度/主体几何与当前相机状态。请求体包含 `schema_version = 2` 和本地生成的 UUID `request_id`。上下文在相机页有效；退出相机页、识别类别变化或用户重置时清空。上下文永远不包含旧图像、原始自然语言聊天或跨会话数据。

发送的图像仍只有一次新采集的 JPEG。提示词要求只根据最新图像与结构化上下文决策，不执行上一轮的动作，不识别人物行为；手动选定预设时将风格锁标志与 selected preset ID 发出，且从 `supported_controls` 移除风格动作。

## 响应 schema

响应包含 `schema_version=2`、相同 `request_id`、`summary`、`rationale`、`subject`（`type`、`people_count_class`、`confidence`、归一化主体区域列表）、`crop_confidence`、可选 `reframe_tip`、可选 `crop_rect` 与建议动作。客户端拒绝版本或 request ID 不匹配、分值越界、人数枚举未知、动作超白名单等响应。主体区域用于验证裁剪不会去掉模型声明的主体。

低于 0.65 的主体或裁剪置信度均不得应用裁剪。群体/杂乱场景返回裁剪框时，要保持主体区域列表中的所有人物可见；几何不可验证时按低置信度处理。归一化裁剪框扩展为方形以保持输出原图比例，再验证保留面积不低于 70%。明显重构优先给用户提示移动手机，用户移动后按键重新分析。

## 裁剪几何

将模型框裁剪到当前图像范围后，以中心为锚点修整为方形归一化边长，从而使输出照片保持源图像比例。修整后重新计算面积；少于源画面 70% 时拒绝裁剪并展示 `reframe_tip` 或“请重新取景”的通用说明。保留现有 PreviewView 可见性检查和高分辨率 ImageCapture 裁剪映射。

## 用户意图

以 `Auto` 胶囊作为默认低干扰入口；点开后按本地识别场景构建单选 Chips。不得弹出键盘。关闭弹层不改变当前意图；点击 AI 按钮时将已选 ID 采样进入该请求上下文。类别映射：人像、旅行/街拍（含风景/通用场景回退）、美食。每类最多两项，不匹配场景时只显示自动判断。

## 请求生命周期

- `ActiveCloudRequest` 保存 request ID、请求场景/face bounds/意图、CancellationHandle 和开始时间。
- 点击取消时设置 terminal state、关闭 HTTP 连接、让图像编码检查取消状态并在结束时关闭/释放 `ImageProxy`，并恢复按钮状态。
- 用户拍照、新请求、离开 home camera tab 或检测到新场景/面部主体显著移动都会使活动请求失效。
- 只有 active request ID 匹配、请求未取消、未过 30 秒、场景/主体几何未明显变化时才处理响应；否则仅显示过期提示，不应用动作或触发自动快门。
- 用户请求期间点快门，立即使该请求失效并取消网络调用，然后沿普通拍照流程继续。
- 响应处理和取消都采用单一主线程状态转换，避免迟到回调重新启用错误页面按钮。

## 失败降级

图像采集、网络、解析、版本、主体置信度或裁剪验证失败时，保持当前相机参数/裁剪状态，说明失败原因并允许普通拍摄。部分已通过安全校验的非裁剪建议仍按现有逐项客户端验证执行；低主体置信度不阻止曝光/变焦建议，只禁止 crop。

## 风格和用户控制

如果请求上下文 `style_locked = true`，解析器会拒绝任何 `preset_id`、`preset_strength` 或 `color_style` 动作。其他动作仍经设备/幅度校验；AI 不拍照，自动快门仅按用户现有显式设置触发，并在请求/场景仍有效时执行一次。

## 生命周期清理

退出相机页/Activity 销毁时取消活动 HTTP 请求、释放帧、清除 intent 和上轮结构化上下文；不写入 SharedPreferences、文件、日志或请求预览中的旧图/历史上下文。
