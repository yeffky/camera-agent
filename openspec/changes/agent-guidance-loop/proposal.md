# 提案：带拍摄上下文的 Agent 指导闭环

## 用户价值

让普通用户在用户主动触发下，获得符合当前拍摄意图的构图建议，并可移动手机后继续重新分析；减少不可靠裁剪、过时响应和对用户预设风格的意外覆盖。

## 范围

- 增加不强迫输入的单选拍摄意图入口，按人像、旅行/街拍、美食显示少量选项。
- 在单个拍摄会话中传递版本化、短小的结构化上下文；不保存或重复发送旧图，不引入聊天记录。
- 让模型明确返回主体/人数分类、识别置信度、裁剪置信度和可选重取景提示；不要求识别人物动作。
- 低置信度、严重裁剪、比例变化或主体不完整的裁剪建议由客户端拒绝，并继续普通相机。
- 增加请求 ID、响应版本校验、取消入口及请求过期/画面变化保护。
- 保持用户明确拍照模式、显式自动快门开关、撤销和离线拍摄行为。

## 排除项

- 不新增聊天 UI、自由文字提示、后台分析、连续图片/视频上传或跨会话记忆。
- 不增加拍后云端点评、用户遥测或产品验收分数。
- 不识别人物行为；不开放高级 Camera2 参数或任意模型工具调用。

## 依赖

- 当前 CameraX 单帧采集、ML Kit 场景分析、动作白名单、取景裁剪和撤销快照。
- 当前用户确认的设计决策见 `docs/AGENT_GUIDANCE_DESIGN.md`。
