# 相机 UI 导航与设置分组规范

## 新增需求

### 需求：一级导航清晰可识别

系统 SHALL 在取景、风格预设和模型设置三个一级页面中提供固定底部导航；每项 SHALL 同时显示图标和文字，且当前页面 SHALL 使用持续可见的选中态。

#### 场景：用户切换一级页面

- **当** 用户点按底部任一导航项
- **那么** 对应页面成为可见页面
- **并且** 对应导航项显示选中态，其他导航项显示未选中态

#### 场景：用户通过无障碍服务浏览导航

- **当** 屏幕阅读器聚焦一个导航项
- **那么** 系统能读取该项对应页面的可理解名称

### 需求：设置内容按任务分组

模型设置页 SHALL 将模型连接、拍摄建议请求、最近云端建议和请求预览分别分组，且保留现有字段提示、隐私说明、请求/撤销及凭据管理行为。

#### 场景：用户配置云端模型

- **当** 用户打开模型设置
- **那么** API 基础地址、路径、模型、Temperature 和 API Key 显示在模型连接分组内
- **并且** 请求动作与图像上传说明显示在独立的拍摄建议请求分组内

### 需求：页面切换保持低干扰

一级页面切换 SHALL 使用短暂且不遮盖取景主体的过渡；切换后的页面和导航状态 SHALL 立即与用户最后选择保持一致。

#### 场景：用户在页面间快速切换

- **当** 用户连续点按不同导航项
- **那么** 最后一次选择对应的页面可见且其 Tab 显示选中态
- **并且** 动效不得阻止后续点击或相机操作
