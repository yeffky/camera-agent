# 提案：相机导航与设置页界面整理

## 用户价值

让普通用户更快在取景、风格预设和模型设置间切换，并能在较长的模型设置页中更容易找到连接、拍摄请求和结果信息；通过轻量过渡让页面状态变化更容易感知。

## 范围

- 底部三个一级 Tab 均提供图标、文字标签和明确选中态。
- 增加简短的 Tab 点击反馈和页面淡入过渡。
- 将模型设置按模型连接、拍摄建议请求、最近云端建议、请求预览进行卡片分组。
- 保持 CameraX 预览、相机动作、AI 请求和预设数据行为不变。

## 排除项

- 不实现手动 ISO、曝光时间、白平衡等高级相机控制。
- 不迁移整页到 Jetpack Compose，不替换 CameraX 预览。
- 不改变 API 请求字段、隐私边界、模型配置持久化或照片处理。
- 不执行产品负责人验收或真机兼容性验收。

## 依赖

- 继续使用现有 Kotlin Views、CameraX 与 drawable 资源。
- Compose/Material 组件选型记录于 `docs/ANDROID_UI_COMPONENTS.md`；具体依赖引入另立技术决策。
