# Camera Agent 相机页视觉规范

> 状态：第一轮实现中；产品负责人真机验收稍后执行。

## 视觉目标

让取景画面成为主视觉，把快门、预设与 AI 拍摄引导组织成清晰的操作层。气质为沉浸、克制、可信，避免过多装饰影响用户看清主体。

## 视觉令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| Canvas | `#0A0D12` | 取景以外的页面底色 |
| Surface | `#141923` | 浮层卡片与面板 |
| Surface selected | `#273143` | 当前选择项背景 |
| Text primary | `#F4F5F7` | 标题、主要操作 |
| Text secondary | `#A4ABB7` | 辅助信息、未选项 |
| Focus accent | `#D5E4FF` | 当前焦点、选中图标 |
| AI accent | 紫蓝渐变 | AI 入口与 AI 相关短反馈 |
| Spacing | 4 / 8 / 12 / 16 / 24 dp | 控件内外间距 |
| Corner radius | 12 / 18 / 24 dp | 控件、卡片、主按钮层级 |

颜色用来表达状态而非装饰；照片内容保持最高视觉优先级。

## 相机页层级

1. **取景画面：**全屏 `PreviewView`，按 `FILL_CENTER` 展示；构图辅助线和 AI 裁剪框使用独立 overlay，不在预览画面上堆放说明文字。
2. **顶部状态：**左右放调控和设置入口，中间放轻量场景/构图提示。没有分析结果时显示简短的分析状态；信息过长时最多显示两行。
3. **AI 建议：**在取景顶部下方显示可关闭的玻璃卡片，先显示建议摘要；自动拍摄开关和撤销操作集中放在卡片底部，保持当前用户选择。
4. **底部拍摄区：**渐变遮罩承托控件；快门为视觉中心，AI 是有明确色彩的次操作；当前预设可快速切换。
5. **一级导航：**保持“主界面 / 风格预设 / 模型设置”固定导航，图标、标签、选中态与相机控制区形成一致的暗色视觉系统。

## 预设表现

- 每个预设以名称加小型色彩标记表达风格；不伪造照片缩略图，也不声称色彩标记等同于实际成片效果。
- 选中项使用浅蓝文字、边框和稍亮的底色，未选项降低对比度但仍可读。
- 选中后保留当前实时预览效果，并用短暂状态动画确认选择；不闪白、不遮住构图主体。

## 动效与可访问性

- 常规状态切换控制在约 120–200ms；遵守系统动画缩放设置。
- 所有图标操作有清晰的 TalkBack 名称；建议/状态使用文本表达，不能只靠颜色。
- 触控区域不小于 48dp；底部左右操作与快门之间保留足够间距，降低误触。
- 取景区域持续可见；控件动画不得延迟快门响应或参数应用。

## 技术边界

- CameraX 继续负责相机帧与预览几何；相机页质感由 View、drawable、文字层级和动效定义。
- 当前 `PreviewView` 为 `COMPATIBLE` + `FILL_CENTER`，以覆盖层与预览色彩处理的兼容性为优先。后续如评估 `PERFORMANCE` 模式，需同时检查颜色效果、overlay 坐标和多机型稳定性。
- 本轮不迁移 Compose、不新增 UI 第三方依赖、不更改云端协议、拍照策略和照片结果。
